# Architecture Rules

- Use scalable modular architecture
- Avoid giant files
- Avoid circular dependencies
- Keep systems ECS-compatible
- Rendering must remain performant
- Use worker-compatible architecture
- Maintain deterministic simulation
- Keep networking decoupled
- Keep simulation independent from rendering
- Optimize for multiplayer scalability
- Avoid hardcoded systems
- Use reusable abstractions

# Coding Rules

- Strict TypeScript only
- No any types
- No unused imports
- No dead code
- Use clean naming
- Keep components modular
- Prefer composition over inheritance
- Optimize rerenders
- Avoid prop drilling
- Write scalable abstractions
- Add comments only when necessary

1. Analyze repository first
2. Read roadmap day
3. Create implementation plan
4. Implement incrementally
5. Run lint
6. Run typecheck
7. Run build
8. Fix errors
9. Optimize implementation
10. Generate report
11. Stop for review

# Simulation Rules

- Systems must support large-scale datacenters
- Power systems must be deterministic
- Thermal systems must scale
- Networking must support packet simulation
- Systems must support future multiplayer
- ECS compatibility required
- Worker-thread compatibility required
- Rendering and simulation must remain decoupled

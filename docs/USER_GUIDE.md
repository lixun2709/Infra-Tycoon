# User Guide\n\nWelcome to Infra-Tycoon, the enterprise-grade hyperscaler operations simulator.\n\n## Getting Started\nYou start with an empty floor plan and a base amount of capital. Your goal is to secure contracts, scale out your datacenter infrastructure, and maintain uptime.\n\n## Controls & UI\n- **Map & Terminal**: Access global insights and direct node interactions.\n- **Inspector Panel**: Click on deployed racks to view telemetry, thermal status, and storage utilization.\n- **Hardware Deployment**: Use the build menu to drop CRAC units, UPS generators, and server racks onto the grid.\n\n## Operational Immersion\nThe game natively emits events to an internal Telemetry Logger. Critical system failures (such as PDU breakers tripping) will surface dynamically through UI notifications and log streams.\n\n## Progression\nExperience is earned through deploying hardware and clearing mission objectives. Milestone pacing requires strategic planning rather than rapid-fire clicks.
